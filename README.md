## Notion を CMS として使った(旧)ブログサイト

メンテされてないやつですが、まだ動いております。

###　確認方法

1. [公開用リンク](https://notion-blog-drab-mu.vercel.app/)に飛ぶ
2. ちょっと待つ（loading の画面がないのでが終わるまでは「記事がありません」と表示される）
3. 記事が複数グリッドで表示される
4. 記事を選択する
5. ちょっと待つ（記事内容の fetch が終わるまでは空っぽ）
6. 何かしらは見れるはず

### 使っている技術

- [notionAPI](https://developers.notion.com/)
- [next.js](https://nextjs.org/)
- [vercel](https://vercel.com/)： next.js サーバー置き場
